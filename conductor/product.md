# Product Context
DeepEye Scanner Suite — Platform Keamanan Siber & DAST Berbasis AI. Pengembangan lanjutan dari zakirkun/deep-eye (CLI engine) dengan lapisan Web GUI + REST API agar mudah digunakan semua kalangan (pemula hingga pentester advanced) tanpa CLI. Core value: orkestrasi 11+ AI providers (OpenAI, Claude, Gemini, Ollama, Groq, Mistral, OpenRouter, xAI Grok, LiteLLM, LM Studio, OrcaRouter), 50+ modul kerentanan OWASP Top 10, WAF bypass, Nuclei YAML, OpenAPI ingest, AI false-positive triage & executive summary, live terminal streaming, vulnerability explorer, scan diff/retest, multi-format reporting (HTML, PDF, JSON, SARIF, JUnit, CSV, XLSX) + compliance mapping PCI-DSS v4/SOC2/ISO 27001:2022. Target user: AppSec, pentester, SOC, developer. Single-user local-first deployment.
